## Google Colab を利用する前に

この教材では Python の処理の流れを理解することを目的としています。

Google Colab の AI 補助機能が表示される場合は、次の手順でオフにしてください。

1. 「ツール」を開く
2. 「設定」を選択する
3. 「AI アシスタント」タブを開く
4. 「生成 AI 機能を非表示」にチェックを入れる

または

4. 「生成 AI 機能の使用に同意する」のチェックを外す

設定は後から元に戻せます。

## AI はなぜわかったふりをして答えちゃうの?

AI、使っちゃいますよね。
でも内容が正しいかどうか、確かめるしくみはまだまだなんです。

AI に知らないことを説明してもらったり、考えるきっかけをもらったりしながら、
自分で確かめるのがベストな付き合い方です。

## この教材について

高校生向けに
* データ
* 確率
* プログラミング
の考え方から生成 AI のしくみを体験する教材です。

この教材では、

1. データを整理する
2. 単語を数える
3. 確率を求める
4. 次に出そうな単語を予測する

という流れを通して、生成 AI の基本的な考え方を学びます。
