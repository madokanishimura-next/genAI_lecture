# 生成 AI ごっこ

### 理解しないくせに答えちゃう AI のなかみ教えます

## AI はなぜわかったふりをして答えちゃうの?

AI、使っちゃいますよね。
でも内容が正しいかどうか、確かめるしくみはまだまだなんです。

AI に知らないことを説明してもらったり、考えるきっかけをもらったりしながら、
自分で確かめるのがベストな付き合い方です。

---

## この教材について

高校生向けに
* データ
* 確率
* プログラミング
の考え方から生成 AI のしくみを体験する教材です。

この教材では、

1. データを整理する
2. 単語を数える
3. 確率を求める
4. 次に出そうな単語を予測する

という流れを通して、生成 AI の基本的な考え方を学びます。
